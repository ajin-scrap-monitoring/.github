# Repository README 템플릿

아래 내용을 개발 Repository의 루트 `README.md`에 복사한 뒤 현재 구현에 맞게 작성한다.
선택 섹션에 기록할 내용이 없으면 해당 섹션을 삭제한다.

```markdown
# Project name

Repository의 목적, 사용자와 시스템 내 역할을 1개 또는 2개 문단으로 설명한다.

## 주요 기능

대표 기능과 책임 범위를 기록한다.

## 사전 조건

- Docker Engine version
- Docker Compose plugin version
- Docker Buildx version if local image build is required

## 설정

공개 설정 파일을 준비하는 명령과 반드시 결정할 값을 설명한다. 실제 secret은 기록하지
않는다.

## 빠른 시작

Runtime 구성을 실행하고 첫 유효 결과를 확인하는 최소 명령을 제공한다.

## 개발 환경

Development image, source mount와 필요한 service의 hot reload 실행 방법을 설명한다.
Dev Container를 제공하면 같은 Development 구성을 재사용한다.

## 개발 및 검증

Validation image에서 정적 검사, test와 build 검증을 실행하는 Repository 루트의 단일
명령을 제공한다.

## 배포

배포 산출물과 배포 정본 문서의 진입점을 설명한다.

## 문서

현재 사용하는 정본 문서의 링크와 역할을 기록한다.

## 이용 조건

이 Repository는 코드 검토와 참고를 위해 Public으로 제공하며 프로젝트 소스 코드에 별도
라이선스를 부여하지 않는다.

외부 의존성에는 각 저작권자가 정한 라이선스를 적용한다.
```
