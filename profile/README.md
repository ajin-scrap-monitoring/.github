# Scrap Monitoring

LiDAR와 카메라를 활용하여 스크랩의 적재 상태를 측정하고 관리자가 확인할 수 있도록 제공하는 모니터링 시스템을 개발한다.

## 목표

- LiDAR 기반 적재 높이와 상태 측정
- 카메라 기반 실시간 현장 확인과 보조 처리
- 엣지 장비와 모니터링 서버 간 데이터 전달
- 적재 상태, 변화 추이, 알림과 이력 확인을 위한 대시보드

## 개발 방식

시스템을 독립적으로 개발하고 배포할 수 있는 단위로 나누어 공개 저장소에서 관리한다. 필요한 작업은 Issue로 추적하고 작업 브랜치와 Pull Request를 통해 `main`에 변경을 반영한다.

개발 저장소는 구현 범위가 확정되는 순서에 따라 이 조직에 추가한다.
